# 배달의민족 엔딩 애니메이션

`ending/index.html` — 로고가 연기처럼 일렁이고 번지면서, 오른쪽에서 불어오는 바람에 실려 왼쪽으로 흘러가며 사라지는
엔딩 시퀀스입니다(1.8초). 바람이 불어오는 오른쪽부터 지워집니다.
SVG 필터(노이즈 비틀림 + 흐림 + 채도 감소)를 글자에 직접 적용하며, 끝나면 효과를 걷어내고 글자를 완전히 숨겨 잔상이 남지 않습니다.

- 브라우저로 `ending/index.html`을 열면 자동 재생됩니다. (`?autoplay=0` 이면 자동 재생 안 함)
- 다른 페이지에 붙여 쓸 때는 `window.playBaeminEnding()` 을 호출하면 처음부터 재생됩니다.
- 끝나면 우측 하단 **다시 보기** 버튼이 나타납니다. 버튼으로 재생하면 입김 효과음(Web Audio로 합성)이 함께 나옵니다.
  (브라우저 정책상 사용자 클릭 전에는 소리를 낼 수 없어 자동 재생 시에는 무음입니다.)
- 타이밍은 스크립트 상단 `T` 객체(ms 단위)에서 조절합니다. 사라지는 시간은 `SMOKE_MS`.
- 로고 글꼴은 Google Fonts의 **Do Hyeon(도현체)** 을 사용합니다. 오프라인이면 시스템 고딕으로 대체됩니다.

## 영상 파일
- `export/baemin-ending.mp4` — 1920×1080, 30fps, 6초, H.264, 무음. 브라우저 화면을 프레임 단위로 캡처해 만든 영상입니다(다시 보기 버튼은 제외).
